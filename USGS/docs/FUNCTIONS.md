# Function catalogue

Generated by `splib07 functions --markdown`; do not edit by hand. All wavelengths are in nanometres.

## 1. Get the data

Download the USGS library and build one table of spectra.

| Function | What it does |
|---|---|
| `get_library(home=None, chapters='MS', kinds=('AREF',), library='splib07b', start=350.0, stop=2500.0, step=5.0, refresh=False, **download_kwargs)` | Return a `SpectralLibrary`, downloading and building it only the first time. |
| `download_splib07(dest, pattern='ASCIIdata_splib07b', fallback_pattern='usgs_splib07', extract=True, only_ascii=True, keep_zip=True, item_id=..., base_url=..., progress=None)` | Download (and extract) the library; returns the directory to pass to `build_library`. |
| `list_remote_files(item_id=..., include_children=True, base_url=..., session=None, timeout=60)` | List downloadable files attached to the data release (and its child items). |
| `build_catalog(root, library='splib07b', chapters=None, kinds=('AREF',), families=None)` | Return a DataFrame describing every spectrum file (no spectra are read yet). |
| `read_values(path)` | Read a one-column USGS text file (title line skipped). Deleted channels become NaN. |
| `build_library(root, library='splib07b', chapters=None, kinds=('AREF',), families=None, wavelengths=None, start=350.0, stop=2500.0, step=5.0, min_valid_fraction=0.9, negative='keep', workers=8)` | Read the extracted USGS Splib07 ASCII data into one `SpectralLibrary`. |

## 2. SpectralLibrary: look up and save

The container: spectra on a common wavelength axis plus a metadata table.

| Function | What it does |
|---|---|
| `SpectralLibrary.search(text, column='name')` | Rows whose `column` (default `name`) contains `text`, case-insensitive. The index is the row number. |
| `SpectralLibrary.materials()` | One row per material: chapter and number of spectra, most spectra first. |
| `SpectralLibrary.spectrum(which)` | One spectrum as a 1-D array on this library's wavelengths. `which` is a row number or an exact `name`. |
| `SpectralLibrary.select(mask=None, **filters)` | Subset by boolean mask or by metadata equality / membership. |
| `SpectralLibrary.drop_invalid(min_valid_fraction=0.9)` | Drop spectra with too many NaN channels. |
| `SpectralLibrary.plot(which=None, ax=None, max_n=10, legend=True)` | Line plot of spectra (needs matplotlib). `which`: row numbers / names, or text to search in names; default the first `max_n`. |
| `SpectralLibrary.to_frame(include_meta=True)` | DataFrame with one row per spectrum (metadata columns first, then one column per band). |
| `SpectralLibrary.to_csv(path, include_meta=True)` | Write the library as a CSV (one row per spectrum, one column per band). |
| `SpectralLibrary.save(path)` | Save to a compressed `.npz` (arrays + metadata JSON, loadable without pickle). |
| `SpectralLibrary.load(path)` | Load a library written by `save` (no pickle is used). |

## 3. SpectralLibrary: preprocessing

Each method returns a new library and records the step in `history`.

| Function | What it does |
|---|---|
| `SpectralLibrary.resample(wavelengths, fwhm=None)` | Interpolate onto a new wavelength grid in nm; optional `fwhm` smooths with a Gaussian of that width first. |
| `SpectralLibrary.to_sensor(sensor)` | Convolve to a sensor's bands, e.g. `lib.to_sensor("sentinel2a")`. |
| `SpectralLibrary.smooth(window=11, poly=3)` | Savitzky-Golay smoothing; `window` is in channels and must be odd. |
| `SpectralLibrary.derivative(order=1, window=11, poly=3)` | Savitzky-Golay derivative with respect to wavelength (reflectance per nm^order). |
| `SpectralLibrary.continuum_removed()` | Divide each spectrum by its upper convex hull, so absorption features become dips below 1. |
| `SpectralLibrary.snv()` | Standard normal variate: subtract each spectrum's mean and divide by its standard deviation. |
| `SpectralLibrary.normalized(method='l2')` | Scale each spectrum: `l2` (unit length), `max`, `minmax` or `area`. |
| `SpectralLibrary.clip(lo=0.0, hi=None)` | Limit values to `[lo, hi]` (default: remove negative noise). |
| `SpectralLibrary.apply(fn, label='custom')` | Apply `fn(wavelengths, X) -> X'` (same shape) for custom preprocessing. |
| `SpectralLibrary.pipeline(steps)` | Run steps in order. Each step is a method name or `(name, kwargs)`. |

## 4. SpectralLibrary: features and comparison

Spectral indices and nearest-spectrum search.

| Function | What it does |
|---|---|
| `SpectralLibrary.indices(nd=None, depths=None)` | Spectral indices as columns. |
| `SpectralLibrary.match(query, k=5, query_wavelengths=None)` | Top-`k` library spectra closest to `query` by spectral angle. |

## 5. Preprocessing functions (NumPy)

The same operations on plain arrays `X` of shape (n_spectra, n_bands); NaN = missing.

| Function | What it does |
|---|---|
| `resample(wl_src, X, wl_dst, fwhm=None, gap_factor=3.0)` | Resample spectra to a new wavelength grid. |
| `convolve_to_bands(wl, X, centers, fwhms, shapes=None, min_coverage=0.8)` | Weighted average of each spectrum over each target band (Gaussian or box SRF). |
| `to_sensor(wl, X, sensor)` | Convolve spectra to a sensor's bands (see `usgs_splib07.sensors`). |
| `convolve_srf(wl, X, srf_wl, srf_resp, min_coverage=0.8)` | Convolve to ONE band using an arbitrary spectral response function (e.g. the official ESA file). |
| `smooth(wl, X, window=11, poly=3)` | Savitzky-Golay smoothing (window in channels, must be odd). |
| `derivative(wl, X, order=1, window=11, poly=3)` | Savitzky-Golay derivative with respect to wavelength (units: reflectance per nm^order). |
| `continuum_removal(wl, X)` | Divide each spectrum by its upper convex hull (values in [0, 1], absorption = dips). |
| `snv(X)` | Standard normal variate per spectrum. |
| `normalize(X, method='l2')` | Per-spectrum scaling: `l2`, `max`, `minmax` or `area` (sum). |
| `normalized_difference(wl, X, a_nm, b_nm)` | (A - B) / (A + B) using the channels nearest to the two wavelengths (e.g. NDVI: 842, 665). |
| `band_ratio(wl, X, a_nm, b_nm)` | Ratio A / B using the channels nearest to the two wavelengths. |
| `band_depth(wl, X, left_nm, center_nm, right_nm)` | Absorption depth at `center_nm` relative to a straight continuum between two shoulders. |
| `spectral_angle(X, ref, min_overlap=3)` | Spectral angle (radians) between every row of `X` and `ref`, using shared valid channels. |

## 6. Sensors

Band definitions used to simulate what a sensor would record.

| Function | What it does |
|---|---|
| `get_sensor(name_or_sensor)` | Look up a sensor by name or alias (`sentinel2a`, `landsat8`, `aster`, ...); a Sensor object is returned unchanged. |
| `sensor_from_wavelengths(name, centers, fwhm=None, names=None, shape='gaussian')` | Build a sensor (for example a hyperspectral instrument) from its band centres in nm and optional band widths. |
| `subset_sensor(sensor, band_names)` | Keep only the named bands of a sensor, in the order given (e.g. B2, B3, B4, B8). |
| `register_sensor(sensor, *aliases)` | Add a sensor definition (and optional aliases) to the registry. |
