## 1. Search an area and get its boundary

### `search_area`  
_function in `geedownload.geocode`_

```python
search_area(
    query: str,
    limit: int = 5,
    country_codes: Optional[str] = None,
    lang: str = 'en',
    polygons_first: bool = True,
    base_url: str = 'https://nominatim.openstreetmap.org/search',
    timeout: int = 60,
    feature_type: Optional[str] = None,
)
```

Search a place name and return candidate areas with their boundary geometry.

Example: ``search_area("Masyaf, Syria")``. `country_codes` is e.g. ``"sy,iq"``.
`feature_type` restricts results to ``"country"``, ``"state"``, ``"city"`` or ``"settlement"``.
Respects the Nominatim usage policy (max one request per second).

**Example**

```python
places = gd.search_area("Masyaf, Syria")
for i, p in enumerate(places): print(i, p)
```

### `resolve_aoi`  
_function in `geedownload.aoi`_

```python
resolve_aoi(area, pick: int = 0, name: Optional[str] = None, **search_kwargs)
```

Turn almost anything into an AOI.

`area` can be an AOI, a Place, a place name ("Masyaf, Syria"), a path to a
shapefile/GeoJSON/GPKG, a (west, south, east, north) tuple/list or "w,s,e,n" text,
or a shapely geometry in lon/lat. `pick` selects which search candidate to use.

**Example**

```python
aoi = gd.resolve_aoi("Masyaf, Syria")
aoi = gd.resolve_aoi([42.35, 33.84, 42.55, 33.96])
aoi = gd.resolve_aoi("my_area.shp")
```

### `download_area`  
_function in `geedownload.pipeline`_

```python
download_area(
    area,
    dataset = 'sentinel2',
    start: Optional[str] = None,
    end: Optional[str] = None,
    out_dir = '.',
    bands = None,
    cloud_max: Optional[float] = 20,
    reducer: Optional[str] = None,
    scale: Optional[float] = None,
    crs: Optional[str] = None,
    clip: bool = True,
    mask_clouds: bool = False,
    apply_scale: bool = False,
    per_image: bool = False,
    max_images: int = 10,
    stack: bool = True,
    keep_band_files: bool = True,
    zip_output: bool = False,
    buffer_m: float = 0,
    pick: int = 0,
    name: Optional[str] = None,
    project: Optional[str] = None,
    max_tile_px: int = 1500,
    max_area_km2: Optional[float] = None,
)
```

Find `area`, save its boundary as a shapefile and download `dataset` imagery covering it.

area       place name ("Masyaf, Syria"), shapefile/GeoJSON path, (w, s, e, n) bbox, shapely geometry, AOI or Place
dataset    registry key (see `list_datasets()`: sentinel2, landsat8, modis_ndvi, srtm ...) or any EE asset id
bands      None = dataset defaults/all, "all", band names or group names (e.g. "10m_bands")
per_image  True = download each scene separately (up to `max_images`) instead of one composite
clip       True = pixels outside the true boundary polygon are masked (bbox is always the file extent)
apply_scale  convert to physical units (reflectance 0-1, Kelvin ...) -> float32 files
max_area_km2 refuse areas whose bounding box is larger than this (protects servers / quotas)

**Example**

```python
res = gd.download_area("Masyaf, Syria", "sentinel2", "2023-06-01", "2023-09-30",
                       out_dir="out", cloud_max=10, bands=["B4", "B3", "B2", "B8"],
                       mask_clouds=True, project="my-ee-project")
print(res.shapefile, res.stack, res.metadata)
```

## 4. Maps (cartopy, JPG)

### `plot_map`  
_function in `geedownload.maps`_

```python
plot_map(
    raster = None,
    out_path = 'map.jpg',
    area = None,
    bands = None,
    cmap: str = 'viridis',
    vmin: Optional[float] = None,
    vmax: Optional[float] = None,
    stretch: Tuple[float, float] = (2, 98),
    classes: Union[None, str, Dict[int, Tuple[str, str]]] = None,
    title: Optional[str] = None,
    legend_label: Optional[str] = None,
    source: Optional[str] = None,
    country: Optional[str] = None,
    admin1: bool = False,
    context: bool = True,
    inset: bool = True,
    inset_loc: str = 'right',
    extent: str = 'area',
    grid_step: Optional[float] = None,
    mask_to_area: bool = True,
    boundary_color: str = 'red',
    nodata: Optional[float] = None,
    dpi: int = 200,
    figsize: Tuple[float, float] = (10, 8),
    max_px: int = 2500,
    pad: float = 0.12,
    show: bool = False,
)
```

Draw a map and save it as JPG (or PNG, from the file extension).

raster   GeoTIFF path (e.g. the ``*_stack.tif`` from ``download_area``); None = outline-only map of `area`
area     place name / AOI / bbox / shapefile for the boundary overlay (default: the raster extent)
bands    None = band 1; one name/index = single band with colour bar; three = RGB composite, e.g. ["B4","B3","B2"]
classes  "worldcover" / "dynamic_world" or {value: (label, "#hex")} for categorical rasters (legend patches)
country  country name for the border context and the inset (default: guessed from a place search)
The legend / colour bar is drawn below or beside the map and the country inset to its right: both are
always outside the map frame (`inset_loc` only accepts "right").
extent   when raster is None: "area" (zoom to the area) or "country" (show the whole country)

**Example**

```python
gd.plot_map("out/.../masyaf_sentinel2_stack.tif", "masyaf_rgb.jpg", area="Masyaf, Syria",
            bands=["B4", "B3", "B2"], source="Sentinel-2 SR, summer 2023")   # RGB
gd.plot_map(stack, "ndvi.jpg", area="Masyaf, Syria", bands="NDVI", cmap="RdYlGn")        # colour bar
gd.plot_map(stack, "lc.jpg", area="Masyaf, Syria", classes="worldcover")                 # class legend
```
